# papex-desktop 项目记忆

## 项目概况（2026-08-18 建立）
- 定位：Papex 桌面科研工作平台（Win/Linux/macOS）：本地优先文献库+PDF深度阅读+批注+引用管理+离线全文索引。独立 GitHub 仓库 Maicarons/papex-desktop，License Apache-2.0（已拷贝，Copyright 2026 The Papex Authors）。
- 上游：papex 后端；类型统一从 openapi.json 生成（scripts/gen-types.sh），禁手写。

## 技术栈（已拍板）
- Tauri 2.x（2.11+，Rust 2021 edition + 系统 WebView：Win WebView2/mac WKWebView/Linux WebKitGTK 2.44+）
- Vite 6+ + React 19 + TS strict + Tailwind 4（@tailwindcss/vite）+ shadcn 风格 + ECharts 6
- PDF：pdfjs-dist 4.x（前端渲染，文本层做高亮定位）+ pdfium-render（Rust 导入解析）
- 本地库：SQLite（rusqlite）papex_local.db；全文索引 tantivy（P2）；钥匙串 keyring crate
- 更新：tauri-plugin-updater（GitHub Releases + latest.json 签名）；通知/单实例官方插件
- 测试：Vitest（前端≥80%）+ cargo test/clippy（Rust 关键模块≥85%）+ Playwright E2E
- pnpm 9+；前端 + src-tauri 单仓

## 架构与约定
- 目录：src/app(routes/layout)/src/features(library|reader|citations|graph|stats|upload|sync|settings)/src/lib(api|tauri bridge|storage|citations|theme)/src-tauri/src(commands: pdf|db|index|keyring|upload|system, db/migrations+DAO, indexer, sync)
- 前端↔Rust：全部走 bridge.ts 类型化 invoke（如 pdf:parse、db:query_library、keyring:get）；前端永不直接碰文件系统；路径统一 app_cache_dir() 防穿越
- 本地库表：papers_cache/versions_cache/annotations(sync_state: local|pending|synced|conflict)/reading_progress/collections/sync_queue(指数退避)/settings
- 冲突策略：last-write-wins + updated_at 版本号；冲突标 conflict 由 UI 处理

## Tokens 系统（与 app 同一契约）
- 同 papex-app：accessToken JWT 15min + refreshToken 30d 轮换+设备绑定（platform=desktop）
- 持久化：Windows Credential Manager / macOS Keychain / Linux SecretService（无桌面环境回退加密文件 0600）；refreshToken 永不落 SQLite/日志

## 上传功能（硬性要求，P1 全实现）
- PDF 投稿：POST /api/papers（multipart）+ /api/papers/[id]/pdf（追加版本）
- 本地 PDF 导入：拖放→Rust pdf:parse 提取元数据→用户确认→POST /api/papers/import
- 头像：POST /api/me/avatar（≤5MB）；论文封面：POST /api/papers/[id]/cover（≤10MB）；笔记配图 P2：POST /api/notes/[id]/attachment
- 统一 features/upload/upload.ts：校验/进度/失败重试

## 后端新增接口（阻塞依赖，与 papex-app 共享契约）
- POST /api/auth/login(App模式)/refresh/logout、GET/DELETE /api/me/devices(/:id)
- GET/PUT /api/reading-progress/[paperId]、GET/POST/PUT/DELETE /api/notes
- POST /api/me/avatar、POST /api/papers/[id]/cover（新）、POST /api/papers/import（已有）
- 新表：devices / reading_progress / notes / paper_covers（或 versions 加 cover_url）——由 papex 主仓库排期

## 功能范围（P0-P3 全实现；admin 不实现）
- P0：认证(登录/多账号)、三栏文献库(257分类双语)、在线检索(关键词+语义)、pdf.js 阅读器(翻页/缩放/搜索/书签/进度/深色)、高亮+笔记(本地+云同步)、离线PDF缓存、引文图谱、订阅通知、托盘+快捷键(Ctrl/Cmd+K)+单实例
- P1：CSL 引用(GB/T 7714/APA/MLA≥10)+BibTeX/RIS 导出、LaTeX 集成(papex-latex)、保存的搜索、阅读统计、双栏对比、上传(见上传功能)
- P2：tantivy 本地全文索引、协作视图(协审/背书/评论只读)、快捷键面板、首次启动引导
- P3：Ollama 本地 embedding 离线语义、插件系统雏形、Word 集成评估
- 排除：投稿审核、admin/管理后台、协审工作流

## 决策记录
- 选 Tauri 2 而非 Electron：常驻型应用内存/启动体感（30-50MB vs 120-400MB）、React 资产复用、Rust 干重活（PDF/索引/钥匙串）
- WebView 兼容：开发期 Chromium 验证，发布前三平台视觉回归；保守 CSS 子集
- Rust 保持薄（仅原生能力，前端 80% 工作量）
- 发布：语义化 0.x.0；CI ci.yml→build.yml(三平台矩阵)→release.yml(tag v* 签名+Release+更新清单)
